# LazyBuddy v1.2.2: supported route

v1.2.2 is prepared for release, but this documentation does not publish a tag
or marketplace artifact.

1. After v1.2.2 is published, clone its release tag and use its durable
   lifecycle entrypoint:

   ```bash
   git clone --branch v1.2.2 https://github.com/elvinzhao10/LazyBuddy.git
   node "<checkout>/lazybuddy-plugin/scripts/lazybuddy-lifecycle.js" onboard \
     --source https://github.com/elvinzhao10/LazyBuddy/releases/tag/v1.2.2 \
     --install-root "<absolute-install-root>" --project "<absolute-project-root>" --json
   ```

2. Use the installed launcher for package checks:

   ```bash
   node "<install-root>/LazyBuddy/launcher.js" status \
     --install-root "<install-root>" --project "<project-root>" --json
   ```

3. Choose one host route. For CodeBuddy CLI and CodeBuddy IDE with the CLI
   available, add the launcher-reported release root as a local marketplace and
   install `lazybuddy@lazybuddy`. For WorkBuddy, choose the release-local
   `lazybuddy-plugin` directory containing `.workbuddy-plugin/plugin.json` in
   the current build's visible plugin/marketplace flow.

4. Automatic workflow selection chooses the smallest sufficient existing
   workflow from task risk and complexity. Until a fresh host observation, this
   is selection-only and does not claim host loading or dispatch. Start a fresh
   host session: host readiness requires a visible LazyBuddy Skill or command
   and all six MCP servers: `run-ledger`, `verification`, `status-dashboard`,
   `context-graph`, `code-intel`, and `docs`.

   Within a verified workflow surface, orchestration uses a compact
   `TASK/DELTA/REFS/VERIFY` dispatch record with read-only provenance and
   plan-bound safe argv. Runtime work records a real entry artifact; stateful
   work also records a transition artifact. This package behavior is distinct
   from host readiness and does not promote it.

The Skills/manual-MCP route is recovery-only and cannot coexist with the full
plugin route for the same project. Do not claim host readiness without
fresh-session evidence.
