### Verified WorkBuddy hooks.json format (from official docs)

```json
{
  "hooks": {
    "Stop": [
      {
        "matcher": "",
        "hooks": [
          {
            "type": "command",
            "command": "${CODEBUDDY_PLUGIN_ROOT}/scripts/hooks/stop-gate.sh",
            "timeout": 10
          }
        ]
      }
    ]
  }
}
```

- **Hook types:** `command` (shell), `http` (POST to URL), `prompt` (LLM eval), `agent` (agent validator). Use `command` for all hooks — shell scripts are portable and fast.
- **`matcher` field:** for `PreToolUse`/`PostToolUse`, match tool names (e.g., `"Write|Edit"`). For session/prompt/stop events, leave empty or omit.
- **`timeout`:** keep hooks fast (5-10s); heavy work goes to background.
- **Plugin hooks are active when the plugin is enabled** — not gated by `allowUntrustedFrontmatterHooks`.
- **Stop hook can block:** return `{"decision": "block", "reason": "..."}` in stdout to prevent the agent from stopping.
- **PreToolUse hook can deny:** return `{"hookSpecificOutput": {"hookEventName": "PreToolUse", "permissionDecision": "deny", "permissionDecisionReason": "..."}}` to block a tool call.

### Critical design rules

- **Use `${CODEBUDDY_PLUGIN_ROOT}`** in all hook commands and script paths — never hardcode paths.
- **Context-pressure detection:** if the transcript/payload contains `context compacted`, `context_length_exceeded`, or similar markers, hooks should pass through gracefully (don't block stop, don't inject) — this prevents infinite loops in degraded context. Trace to how LazyCodex's hooks check for this (see `start-work-continuation/src/codex-hook.ts` `transcriptHasContextPressureMarker`).
- **NEVER log secret values** — redact before writing to `events.jsonl`. Use `[REDACTED: N chars, prefix PREFIX]` format.
- **Keep hooks fast** (5-10s timeout). Heavy work (evidence verification, checkpoint creation) should be minimal; the hook just records/reads state.
- **Stop hook must be idempotent** — if `stop_hook_active` is true in the payload, don't re-block (prevents infinite continuation loops). Trace to LazyCodex's `input.stop_hook_active` check.
- **SubagentStop evidence verification** — follow LazyCodex's pattern: extract `EVIDENCE_RECORDED: <path>` from the agent's last message, validate the path resolves inside the evidence root (use `realpath` to prevent symlink escapes), check the file exists and is non-empty, and is not a symlink itself. Max 3 retries before giving up.
- **Shell scripts** — use `#!/usr/bin/env bash` for portability. Parse JSON payloads from stdin with `python3` or `jq`. Document this choice in `docs/lazybuddy-hooks.md`.
