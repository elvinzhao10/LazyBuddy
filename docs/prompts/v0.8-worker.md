### Verified WorkBuddy MCP format (from official docs)

```json
{
  "mcpServers": {
    "run-ledger": {
      "command": "node",
      "args": ["${CODEBUDDY_PLUGIN_ROOT}/mcp/run-ledger/server.js"],
      "cwd": ".",
      "required": false
    }
  }
}
```

- Use `${CODEBUDDY_PLUGIN_ROOT}` for plugin-bundled paths.
- `"required": false` means the plugin works even if the MCP server fails to start (graceful degradation).
- MCP servers communicate via stdio (JSON-RPC). Since the workspace has no Node deps installed, **use shell scripts with python3 for JSON-RPC handling** — consistent with v0.6/v0.7. Each server is a `server.sh` that reads JSON-RPC requests from stdin and writes responses to stdout. Document this choice.
