### Verified WorkBuddy agent facts (from official docs)

Agent files live at `agents/*.md` with YAML frontmatter. Confirmed fields:
- `name` — role identifier
- `description` — expertise and when to invoke (used for routing)
- `model` — model variant (`default` | `lite` | `reasoning`); inherit unless there's a clear reason
- `effort` — reasoning effort (`low` | `medium` | `high` | `xhigh`)
- `maxTurns` — max agentic turns before stopping
- `tools` — allowed tools (whitelist)
- `disallowedTools` — forbidden tools (blacklist)
- `skills` — skills this agent can load
- `memory` — whether agent has memory access
- `isolation` — `"worktree"` is the only valid value (use only when needed)

**Safety limits (from official docs):** agents do NOT support `hooks`, `mcpServers`, or `permissionMode` fields. Do not include these.

### Authority boundaries (from the spec — enforce via tools + system prompt)

- **Orchestrator:** owns workflow state, task selection, delegation, merge decisions, final completion claim. Never implements directly.
- **Planner:** owns read-only analysis and plan generation. Never writes product code.
- **Implementer:** owns bounded code/docs changes. Cannot spawn subagents.
- **Verifier:** owns command execution and verification summaries. Read-only (no Write/Edit).
- **Reviewer:** owns human-like review and accept/revise/reject decisions. Read-only.
- **Librarian:** owns memory, command index, parity ledger, known-gap updates. Write access to memory files only.
- **Migration Planner:** owns host-adapter generation. Read-only.
- **Context Indexer:** owns repo map and method evidence indexing. Write to `.lazybuddy/context/` only.
- **Security Auditor:** owns permission, secret, unsafe command, and overreach review. Read-only.

### Hard constraints

- **Valid YAML frontmatter** on every agent file — verify by parsing.
- **No `hooks`, `mcpServers`, or `permissionMode` fields** in agent frontmatter (not supported per official docs).
- **Verifier, reviewer, gate-reviewer, security-auditor must be read-only** (`disallowedTools: [Write, Edit]`).
- **Implementer cannot spawn subagents** (orchestrator-only capability).
- **Every agent maps to at least one LazyCodex behavior** OR is marked as a WorkBuddy-native enhancement (context-indexer, security-auditor, migration-planner).
- **No two agents have conflicting authority** — verify the authority boundaries don't overlap.
- **Model policy:** inherit (`default`) unless there's a clear reason; stronger model (`reasoning`, `xhigh` effort) for planning/review/security; faster model (`lite`, `low` effort) for indexing/exploration.
