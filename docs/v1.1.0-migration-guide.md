# v1.1.0 migration guide — native host boundaries

v1.1.0 retained separate authority for CodeBuddy, WorkBuddy, and CodeBuddy
Code. Package readiness did not promote host readiness, and generated host
candidates remained inert until the selected host produced matching,
fingerprint-bound runtime evidence.

Treat v1.1 receipts and release evidence as immutable compatibility inputs.
They are not current writers and cannot promote a v1.2 host. Preserve
caller-owned or modified files during removal, and remove only unmodified
assets proven receipt-owned.
