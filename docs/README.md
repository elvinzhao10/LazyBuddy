# LazyBuddy documentation handoff

This directory is the maintained documentation entry point for LazyBuddy. Detailed
explanations are intentionally left for the next documentation pass.

Start with [handoff.md](handoff.md) for the package boundaries, source-of-truth
files, validation commands, and documentation ownership.

Legacy working notes are private local material under `dev/docs/`. They are
ignored by Git, are not release content, and must never be used as a package
runtime dependency.
