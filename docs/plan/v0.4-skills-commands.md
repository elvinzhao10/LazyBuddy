Skill behavior details:
init-deep:
- Inspect repo structure.
- Identify language/runtime/package manager.
- Identify common commands.
- Identify test/lint/build scripts.
- Identify existing docs and architecture.
- Generate or update .lazybuddy/context/index.md.
- Generate or update .lazybuddy/context/commands.json.
- Generate or update .lazybuddy/context/project-map.json.
- Do not modify product code.
ulw-plan:
- Use read-only analysis.
- Produce implementation plan.
- Write .lazybuddy/runs/<run_id>/plan.md.
- Write task graph to .lazybuddy/runs/<run_id>/state.json when state ledger exists.
- Ask only blocking questions.
- Do not implement.
start-work:
- Load plan and state.
- Select next bounded task.
- Implement one bounded unit.
- Update run log.
- Invoke verifier before marking done.
ulw-loop:
- Continue bounded work cycles.
- After each cycle, verify, review, update memory, checkpoint.
- Stop only when complete, blocked, or approval/budget required.
verifier:
- Discover available checks.
- Run relevant checks.
- Summarize exact commands and results.
- Distinguish pass, fail, warning, skipped, and not applicable.
reviewer:
- Review changed files against intent and LazyCodex parity.
- Check for overreach, missing tests, and missing docs.
- Produce accept, reject, or revise decision.
librarian:
- Update memory after accepted changes.
- Update command index, parity ledger, known gaps, and risk register.
- Avoid rewriting canonical method map unless repo evidence changes.
migration-planner:
- Create host-adapter plans for future platforms.
- Require canonical repo inspection and semantic mapping.
Verification:
- Every Skill has a corresponding command.
- Every command has usage, inputs, outputs, success criteria, and failure behavior.
- Every Skill maps back to the original LazyCodex method map.
- Run plugin validation if available.
- Run docs consistency check.
- Update parity ledger.
Required output:
- Skill inventory table
- Command inventory table
- What I inspected
- What I found
- What I changed
- How to run it
- Verification performed
- Remaining gaps
- Next prompt to paste
