Your task:
Implement workbuddy hooks and permission/safety controls so Lazyworkbuddy does not rely only on advisory prompts.

If the workspace language/package manager suggests TypeScript, prefer TypeScript/Node scripts.

Document the choice.
Hook behavior:
SessionStart:
- Detect active .lazyworkbuddy run.
- Load current run summary.
- Inject or print current objective, next task, blockers, and verification status.
- Warn if project memory or rules are missing.
- Do not mutate code.
UserPromptSubmit:
- Detect Lazyworkbuddy command intent.
- Suggest the correct command if the user asks for long-horizon work.
- Warn on pasted secrets or dangerous requests.
- Do not block ordinary prompts unless a safety rule is violated.
PreToolUse:
- Block obvious secret reads, destructive deletes, unsafe overwrites, and unauthorized external sends.
- Require explicit approval for:
  - deleting files
  - overwriting source artifacts
  - publishing external content
  - network operations if not already approved
  - running install scripts
  - changing permission/settings files
  - accessing secret-like paths
- Respect workbuddy permission rules.
PostToolUse:
- Append tool-use summary to .lazyworkbuddy/runs/<run_id>/events.jsonl if an active run exists.
- Record changed file paths.
- Record artifact paths.
- Do not log secret values.
PostToolUseFailure:
- Append failure event.
- Suggest retry/fallback/blocker classification.
PreCompact:
- Save current run checkpoint.
- Preserve:
  - objective
  - plan path
  - completed tasks
  - current task
  - verification failures
  - blockers
  - next action
  - files changed
Stop:
- Prevent or warn against premature completion if:
  - active run exists
  - required verification gates failed or were not run
  - reviewer did not accept
  - known blockers remain
- Allow stop if blocked with explicit blocker report.
StopFailure:
- Write failure record and recovery suggestion.
TaskCreated / TaskCompleted:
- Mirror workbuddy task events into Lazyworkbuddy run ledger where possible.
SubagentStart / SubagentStop:
- Record agent lifecycle events and output locations.
Project settings update:
- Update .workbuddy/settings.json only if needed.
- Use deny rules for secrets.
- Use ask rules for high-risk operations.
- Avoid broad bypass permissions.
