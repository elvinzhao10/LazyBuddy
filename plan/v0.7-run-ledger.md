Rules:
- All state writes must be atomic.
- Every state transition must append to events.jsonl.
- State must be recoverable from latest state.json plus event log.
- Validate state against JSON schema before saving.
- Never mark run complete unless verification and review permit it.
- Do not rely on chat context for status.
- All agent outputs must be saved before synthesis.
- All artifacts must have provenance metadata.
- Repair tasks must be explicit, not hidden inside prose.
Update Skills:
- start-work must use the state ledger.
- ulw-loop must use the state ledger.
- verifier must write gate results.
- reviewer must write review decision.
- librarian must write memory update records.
- finalize must refuse completion unless gates pass or waivers are recorded.
