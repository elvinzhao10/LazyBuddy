## Compatibility and authority

- Existing named workflows and simple-task selection remain intact. No new mandatory elaborate workflow was added for simple operations.
- Source binding is bounded to 5,000 files/32 MiB, ignores ignored application files and excludes native runtime stores. The plan has a separate digest. Unstable/unsafe capture makes approval unavailable.
- Review actor strings provide local attribution, not authenticated host permission. Manual review consumption does not authorize a native attempt or create verification authority.
- Historical records without retained definitions remain unreported. Compaction reduces duplicate active events, not total retained archive storage.
- Host loading, model-backed execution, hook delivery, embedding, chat handoff and wake require separate observed evidence. Deferred tests remain pending. No host trust/settings/account changes are part of this PR.
