# LazyBuddy

[![Current release v1.4.1](https://img.shields.io/badge/release-1.4.1-0d9488)](https://github.com/elvinzhao10/LazyBuddy/releases/latest)

**Plan, build, and verify in CodeBuddy and WorkBuddy.**

Turn coding requests into focused work, editable plans, and results you can check.

- Editable plans and persistent project decisions.
- Focused execution with verification and evidence.
- Checkpoints and handoffs for ongoing work.
- A local dashboard for plans, progress, and package health.

## Get started

Use the [LazyBuddy installation guide](https://github.com/elvinzhao10/LazyBuddy/blob/main/docs/03-install-and-host-verification.md) for your app. Confirm the integration in a fresh session before starting project work.
